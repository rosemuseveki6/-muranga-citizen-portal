# Murang'a Citizen Portal

Live: https://rosemuseveki6.github.io/-muranga-citizen-portal/
Repo: https://github.com/rosemuseveki6/-muranga-citizen-portal

A platform for Murang'a residents to report public service issues.

## Features

1. **Citizen Submit Request (25%)**
- Category: Water, Roads, Garbage, Electricity
- Location + Description
- Image upload with preview
- Validation

2. **Admin Dashboard (25%)**
- Password protected: admin123
- View all reports
- Filter by Status (Pending/In Progress/Resolved)
- Search by location
- Update status
- Export CSV (Bonus)

3. **Status Tracking (15%)**
- Badge colors for status
- Citizen can track own requests

4. **Analytics (15%)**
- Total, Pending, In Progress, Resolved cards

5. **Bonus (10%)**
- Responsive design
- LocalStorage persistence
- Murang'a branding (Green/Gold)

## How to Use
1. Citizen: Enter name + phone -> Submit request
2. Admin: Click Admin Dashboard -> Enter password admin123 -> Manage requests
3. Search & Filter + Export CSV

## Tech
HTML, CSS, Vanilla JS, LocalStorage, GitHub Pages

## Test Flow
Citizen Login -> Submit Request -> Admin Login (admin123) -> Update to Resolved -> Check Analytics
